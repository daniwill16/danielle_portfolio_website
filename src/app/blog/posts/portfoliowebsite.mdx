## Built a Personal Portfolio Website

As part of my academic and professional development, I designed and deployed a fully functional personal portfolio website from scratch. Using **Next.js** as the framework, **GitHub** for version control, and **Vercel** for deployment, I navigated real-world development workflows including pushing code, resolving build errors, and managing a live production site. This project pushed me to learn new tools independently and reinforced my ability to problem-solve under pressure.
