## Overview
This project focuses on automating the segmentation of the left ventricle from cardiac MRI scans. Manual contouring is time‑consuming and limits the scalability of tasks like mesh generation and analysis. By developing a deep learning–based segmentation pipeline, the goal is to accelerate the transition from raw MRI data to computational modeling, ultimately supporting faster diagnostic and prognostic workflows.

## Problem Motivation
MRI scans appear exclusively in grayscale, and the lack of clear visual boundaries makes automated segmentation challenging. Existing tools often require manual input for each image, which becomes impractical when large datasets are needed for research pipelines. Automating this step would save significant time and enable large‑scale studies that rely on high‑volume segmentation data.

## Dataset
The project uses the **Sunnybrook Cardiac Dataset (SCD)**, which provides:
- **805 manually drawn inner contours**  
- **420 manually drawn outer contours**  
- Corresponding MRI images  
- Additional unlabeled images for potential training or testing  

Contours are provided as `.txt` files containing X/Y coordinate pairs that outline the inner and outer ventricular walls.

## Technical Approach
- **Model Architecture:** U‑Net, chosen for its strong performance in biomedical image segmentation  
- **Training Strategy:**  
  - 80/20 train–test split  
  - Within training: 90/10 train–validation split  
- **Output Format:** Model‑generated contours matching the coordinate‑based format of the SCD dataset  
- **Future Flexibility:** Additional unlabeled images can be manually contoured to expand the dataset if needed  

The goal is to produce accurate, automatically generated segmentations that can be overlaid on MRI images for verification and used in downstream mesh‑generation workflows.

## Reflection
This project represents a crucial step in building a fully automated pipeline from MRI acquisition to FEA‑ready meshes. It strengthens skills in computer vision, biomedical imaging, and deep learning while contributing to research aimed at improving patient‑specific modeling and clinical decision support.
