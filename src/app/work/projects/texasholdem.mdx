## Overview
This project involved developing a Texas Hold ’Em poker bot capable of operating in a competitive, imperfect‑information environment. Built using PyTorch and the OpenSpiel framework, the model applies reinforcement learning techniques to learn and refine decision‑making strategies through simulated gameplay and live competition.

## Key Features
- **Reinforcement Learning Model:** Trained using OpenSpiel environments and PyTorch neural networks  
- **Neural Network Architecture:** Dense input layers, multi‑action outputs, and SoftMax‑based probability distributions  
- **Performance Improvements:** Increased win accuracy from 0% to 64% and reduced model loss to 1.22%  
- **Competitive Evaluation:** Survived 37 hands against peer‑developed bots in live testing  
- **Behavioral Analytics:** Identified strategy patterns, weaknesses, and model limitations through post‑training analysis
