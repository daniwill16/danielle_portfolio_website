## Overview
Steam Achievement Fetcher is a full‑stack web application built to deliver dynamically generated achievement challenges by connecting directly to the Steam API. The platform retrieves user achievement data, analyzes engagement patterns, and presents personalized challenges and performance insights.

## Key Features
- **Steam API Integration:** Retrieves real‑time achievement data and user activity  
- **Steam OpenID Authentication:** Secure login and identity verification  
- **Dynamic Challenges:** Generates personalized achievement goals based on user progress  
- **Engagement Tracking:** Captures streaks, rankings, social interactions, and activity trends  
- **Dashboards & Leaderboards:** Visualizes performance indicators and competitive standings  
- **Persistent Storage:** Uses Firebase to store user profiles, activity logs, and analytics data
