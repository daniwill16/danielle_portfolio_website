## Overview
This project involves designing and implementing a custom SQL database for a nonprofit organization dedicated to supporting wounded veterans. The goal is to create a reliable, organized system for storing and managing member information, enabling the organization to track participation, outreach, and support services more efficiently.

## Problem Motivation
The organization previously relied on scattered spreadsheets and manual record‑keeping, making it difficult to maintain accurate member data or generate meaningful insights. A centralized database was needed to streamline operations, reduce errors, and support long‑term growth.

## Key Features
- **Centralized Member Records:** Stores personal details, service history, contact information, and membership status  
- **Structured SQL Schema:** Designed relational tables to ensure data integrity and efficient querying  
- **Search & Retrieval Tools:** Enables quick lookup of members based on attributes such as location, service branch, or participation  
- **Scalable Design:** Built to support future additions such as event tracking, donations, or volunteer activity  

## My Contributions

- Implementing SQL queries for data entry, updates, and reporting  
- Ensuring data consistency through constraints, indexing, and normalization  
- Collaborating directly with the organization’s leadership to understand operational needs and translate them into technical requirements
